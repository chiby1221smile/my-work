# CAMPFIREマーケティング戦略資料 - Gemini API完全自動生成版

Google Apps Script (GAS) + **Gemini API** で動作する、CAMPFIREクラウドファンディング向けマーケティング戦略資料の**完全自動生成ツール**です。

## 🚀 特徴

- **Gemini AIによる完全自動生成**: スプレッドシートのデータから、**60ページ前後の詳細なマーケティング戦略資料**をAIが自動作成
- **CAMPFIRE成功法則の注入**: 初日30%達成で成功率90%、お気に入り100件必須など、実績データに基づいた戦略を自動反映
- **専門用語ゼロ**: AIが中学生でもわかる日本語で戦略を記述（KPI→「数値目標」、リーチ→「見た人の数」など）
- **文字見切れ防止**: 文字数に応じてフォントサイズを自動調整
- **A4縦型レイアウト**: 595x842ポイント（21cm × 29.7cm）のプレゼンテーション形式
- **分割リレー生成**: 10ページ×6回に分けて生成し、タイムアウトを回避
- **Not Foundエラー対策**: 複数のGeminiモデルを自動試行するリトライ機能

## 🔧 セットアップ方法

### 1. Gemini APIキーの取得

1. https://aistudio.google.com/app/apikey にアクセス
2. 「Create API Key」をクリック
3. APIキーをコピー

### 2. Googleスプレッドシートを作成

1. 新しいGoogleスプレッドシートを作成
2. 1行目にヘッダーを設定（任意）
3. 2行目以降にクライアント情報を入力

#### スプレッドシートの列構成

| 列 | 項目名 | 説明 | 例 |
|---|---|---|---|
| A | 起案者名 | クライアントの名前 | 四ヶ所 伸一 |
| B | 目標金額 | プロジェクトの目標金額（数値） | 300000 |
| C | 背景 | プロジェクトの背景 | 不登校の子どもたちの居場所... |
| D | URL一覧 | SNSのURL（改行区切り） | https://x.com/username |
| E | 実現したいこと | プロジェクトで実現したいこと | 子どもが不登校でも大丈夫... |
| F | プロジェクト名 | プロジェクトの名前 | 認定NPO法人再チャレンジ東京 |

### 3. Google Apps Scriptにコードを貼り付け

1. スプレッドシートで「拡張機能」→「Apps Script」を開く
2. 既存のコードを削除
3. 以下の2つのファイルを作成し、それぞれコードを貼り付け：
   - `コード.gs`
   - `スライド生成.gs`

### 4. APIキーを設定

`コード.gs` の6行目を編集：

```javascript
const MY_API_KEY = "あなたのGemini APIキーをここに貼り付け";
```

### 5. 保存して実行

1. プロジェクトを保存（Ctrl + S / ⌘ + S）
2. スプレッドシートをリロード
3. メニューに「🤖 CAMPFIRE AI戦略」が表示されます

## 📖 使い方

### 基本的な使い方

1. スプレッドシートにクライアント情報を入力
2. メニューから「🤖 CAMPFIRE AI戦略」→「🚀 戦略資料を自動生成（Gemini版）」を選択
3. クライアントを選択（複数ある場合）
4. 生成完了を待つ（15〜20分、各章ごとに通知）
5. 完成したスライドのURLをコピーして開く

- **🚀 戦略資料を自動生成（Gemini版）**: メインの生成機能（60ページ自動生成）

- **📂 最新資料のURL表示**: 前回生成した資料のURLを表示

## 🐛 トラブルシューティング

### 「APIキーが設定されていません」エラー

`コード.gs` の6行目でAPIキーが正しく設定されているか確認してください。

```javascript
const MY_API_KEY = "YOUR_API_KEY_HERE";  // ← ここを変更
```

### 「すべてのモデルで接続失敗しました」エラー

1. APIキーが正しいか確認
2. https://aistudio.google.com/app/apikey でAPIキーの状態を確認
3. Gemini APIの無料枠を使い切っていないか確認

### タイムアウトエラー

分割生成方式を採用していますが、それでもタイムアウトする場合：

1. スプレッドシートのデータ量（背景や実現したいことの文字数）を減らす
2. 再度実行する

### レイアウトがずれる

文字見切れ防止機能により自動調整されますが、極端に長いテキストの場合：

1. スプレッドシートの入力内容を簡潔にする
2. 生成後に手動でスライドを調整する

### Geminiが日本語で応答しない

プロンプトに日本語指示を含めていますが、稀に英語で応答する場合があります。その場合は再実行してください。

## ⚙️ カスタマイズ

### 色設定の変更

`コード.gs` の `色設定` オブジェクトで色を変更できます。

```javascript
const 色設定 = {
  背景色: '#FFF9E6',
  見出し帯: '#FF9500',
  // ...
};
```

### フォントサイズの調整

`コード.gs` の `フォントサイズ` オブジェクトで調整できます。

```javascript
const フォントサイズ = {
  タイトル最大: 32,
  タイトル最小: 22,
  // ...
};
```

### 章の構成を変更

`スライド生成.gs` の `章タイトルリスト` を編集してください。

```javascript
const 章タイトルリスト = [
  '導入・プロジェクト概要',
  '成功の実態データ',
  // ... あなたの章を追加
];
```

### ページ数の変更

`スライド生成.gs` の249行目を編集：

```javascript
- 第${章番号}章「${章タイトル}」の内容として、10ページ分の詳細な戦略を提案してください
```

「10ページ」を任意の数値に変更してください。
