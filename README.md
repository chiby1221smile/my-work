# CAMPFIREマーケティング戦略資料ジェネレーター

Google Apps Script (GAS) で動作する、CAMPFIREクラウドファンディング向けマーケティング戦略資料の生成ツールです。

## 🚀 特徴

- **60ページの充実したコンテンツ**: スプレッドシートのデータから、詳細なマーケティング戦略資料を自動生成
- **CAMPFIRE成功法則を網羅**: 初日30%達成で成功率90%、お気に入り100件必須など、実績データに基づいた戦略を収録
- **専門用語ゼロ**: 中学生でもわかる日本語で戦略を記述（KPI→「数値目標」、リーチ→「見た人の数」など）
- **文字見切れ防止**: 文字数に応じてフォントサイズを自動調整
- **A4縦型レイアウト**: 595x842ポイント（21cm × 29.7cm）のプレゼンテーション形式
- **デザイン確認用テストデータ**: ボリュームのある60ページで全体のデザインを確認可能

## 📋 生成される資料の構成

### 全6章・約62ページ

1. **表紙・目次** (2ページ)
2. **第1章: 導入・プロジェクト概要** (10ページ)
   - プロジェクトの背景と目的
   - ターゲット層の分析
   - 実現したいことの具体化
3. **第2章: 成功の実態データ** (10ページ)
   - CAMPFIRE成功事例の分析
   - 初日15%・3日間30%の法則
   - 支援者の8割は身近な人というデータ
4. **第3章: 準備フェーズ「まずは100人」** (10ページ)
   - お気に入り100件登録の戦略
   - 連絡先リスト300名の作成方法
   - 個別メッセージテンプレート（コピペ厳禁の理由）
5. **第4章: 初動3日間「スタートダッシュ」** (10ページ)
   - Day 1の戦術（初日30%達成のための具体策）
   - Day 2-3のフォローアップ戦略
6. **第5章: SNS・発信戦略** (10ページ)
   - X (Twitter)、Note、Instagram、Amebaの活用法
   - 投稿頻度とハッシュタグ戦略
   - 進捗報告のコツ
7. **第6章: まとめ・次の一手** (10ページ)
   - 成功の3原則
   - チェックリスト
   - FAQ

## 🔧 セットアップ方法

### 1. Googleスプレッドシートを作成

1. 新しいGoogleスプレッドシートを作成
2. 1行目にヘッダーを設定（任意）
3. 2行目以降にクライアント情報を入力

#### スプレッドシートの列構成

| 列 | 項目名 | 説明 | 例 |
|---|---|---|---|
| A | 起案者名 | クライアントの名前 | 四ヶ所 伸一 |
| B | 目標金額 | プロジェクトの目標金額（数値） | 300000 |
| C | 背景 | プロジェクトの背景 | 不登校の子どもたちの居場所... |
| D | URL一覧 | SNSのURL（改行区切り） | https://x.com/username |
| E | 実現したいこと | プロジェクトで実現したいこと | 子どもが不登校でも大丈夫... |
| F | プロジェクト名 | プロジェクトの名前 | 認定NPO法人再チャレンジ東京 |

### 2. Google Apps Scriptにコードを貼り付け

1. スプレッドシートで「拡張機能」→「Apps Script」を開く
2. 既存のコードを削除
3. 以下の2つのファイルを作成し、それぞれコードを貼り付け：
   - `コード.gs`
   - `スライド生成.gs`

### 3. 保存して実行

1. プロジェクトを保存（Ctrl + S / ⌘ + S）
2. スプレッドシートをリロード
3. メニューに「📊 CAMPFIRE戦略」が表示されます

## 📖 使い方

### 基本的な使い方

1. スプレッドシートにクライアント情報を入力
2. メニューから「📊 CAMPFIRE戦略」→「🚀 戦略資料を自動生成」を選択
3. クライアントを選択（複数ある場合）
4. 生成完了を待つ（数分）
5. 完成したスライドのURLをコピーして開く

### メニュー機能

- **🚀 戦略資料を自動生成**: メインの生成機能（60ページ生成）
- **📂 最新資料のURL表示**: 前回生成した資料のURLを表示

## 🎨 デザイン仕様

### カラーパレット

- **背景色**: `#FFF9E6` (クリーム色)
- **見出し帯**: `#FF9500` (オレンジ)
- **アクセント**: `#FFD966` (黄色)
- **本文色**: `#333333` (ダークグレー)
- **カード背景**: `#FFFFFF` (白)

### レイアウト

- **ページサイズ**: 595 x 842ポイント (A4縦)
- **余白**: 上下左右40pt
- **コンテンツ幅**: 515pt

### フォントサイズ（自動調整）

- **タイトル**: 22〜32pt（文字数に応じて自動調整）
- **見出し**: 16〜22pt
- **本文**: 11〜16pt
- **小文字**: 9〜12pt

## 🐛 トラブルシューティング

### レイアウトがずれる

文字見切れ防止機能により自動調整されますが、極端に長いテキストの場合：

1. スプレッドシートの入力内容を簡潔にする
2. 生成後に手動でスライドを調整する

### 実行エラーが発生する

1. スプレッドシートのデータが正しく入力されているか確認
2. Apps Scriptのプロジェクトを保存しているか確認
3. スプレッドシートをリロードしてメニューが表示されるか確認

## ⚙️ カスタマイズ

### 色設定の変更

`コード.gs` の `色設定` オブジェクトで色を変更できます。

```javascript
const 色設定 = {
  背景色: '#FFF9E6',
  見出し帯: '#FF9500',
  // ...
};
```

### フォントサイズの調整

`コード.gs` の `フォントサイズ` オブジェクトで調整できます。

```javascript
const フォントサイズ = {
  タイトル最大: 32,
  タイトル最小: 22,
  // ...
};
```

### 章の構成を変更

`スライド生成.gs` の `章タイトルリスト` を編集してください。

```javascript
const 章タイトルリスト = [
  '導入・プロジェクト概要',
  '成功の実態データ',
  // ... あなたの章を追加
];
```

### ページ数の変更

`スライド生成.gs` の249行目を編集：

```javascript
- 第${章番号}章「${章タイトル}」の内容として、10ページ分の詳細な戦略を提案してください
```

「10ページ」を任意の数値に変更してください。
