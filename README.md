# CAMPFIREマーケティング戦略資料 自動生成ツール

Google Apps Script (GAS) で動作する、CAMPFIREクラウドファンディング向けマーケティング戦略資料の自動生成ツールです。

## 📋 概要

このツールは、スプレッドシートに入力したクライアント情報を元に、**47ページ前後の詳細なマーケティング戦略資料**を自動生成します。

### 主な特徴

- **完全自動生成**: スプレッドシートのデータから、プロフェッショナルな戦略資料を自動作成
- **動的ページ生成**: SNS情報に基づいて、必要なページだけを生成
- **16:9横長レイアウト**: 960x540ポイントのプレゼンテーション形式
- **分割生成方式**: タイムアウト対策として、3パートに分けて安全に生成
- **PDF準拠デザイン**: 提供されたPDFデザインを忠実に再現

## 📦 ファイル構成

```
.
├── コード.gs             # 定数・ユーティリティ・メイン処理
├── スライド生成.gs       # 表紙・目次・第1章
└── 章スライド.gs         # 第2章〜第9章
```

## 🚀 セットアップ方法

### 1. Googleスプレッドシートを作成

1. 新しいGoogleスプレッドシートを作成
2. 1行目にヘッダーを設定（任意）
3. 2行目以降にクライアント情報を入力

#### スプレッドシートの列構成

| 列 | 項目名 | 説明 | 例 |
|---|---|---|---|
| A | 起案者名 | クライアントの名前 | 山田太郎 |
| B | 目標金額 | プロジェクトの目標金額（数値） | 300000 |
| C | 背景 | プロジェクトの背景 | このプロジェクトは... |
| D | URL一覧 | SNSのURL（改行区切り） | https://x.com/username<br>https://note.com/username |
| E | 実現したいこと | プロジェクトで実現したいこと | ○○を通じて... |
| F | プロジェクト名 | プロジェクトの名前 | ○○制作プロジェクト |

### 2. Google Apps Scriptに貼り付け

1. スプレッドシートで「拡張機能」→「Apps Script」を開く
2. 既存のコードを削除
3. 以下の3つのファイルを作成し、それぞれコードを貼り付け：
   - `コード.gs`
   - `スライド生成.gs`
   - `章スライド.gs`

### 3. Slides APIを有効化

1. Apps Scriptエディタで「サービス」（⊕マーク）をクリック
2. 「Google Slides API」を検索して追加
3. バージョンは `v1` を選択

### 4. 保存して実行

1. プロジェクトを保存（Ctrl + S / ⌘ + S）
2. スプレッドシートをリロード
3. メニューに「📊 CAMPFIRE戦略」が表示されます

## 📖 使い方

### 基本的な使い方

1. スプレッドシートにクライアント情報を入力
2. メニューから「📊 CAMPFIRE戦略」→「🚀 戦略資料を自動生成（分割版）」を選択
3. クライアントを選択（複数ある場合）
4. 生成完了を待つ（各パート完了時に通知）
5. 完成したスライドのURLをコピーして開く

### メニュー機能

- **🚀 戦略資料を自動生成（分割版）**: メインの生成機能
- **📂 最新資料のURL表示**: 前回生成した資料のURLを表示
- **📝 テンプレート行を追加**: サンプルデータの行を追加

## 🎨 デザイン仕様

### カラーパレット

- **背景色**: `#FFF9E6` (クリーム色)
- **アクセント色**: `#FF9500` (オレンジ)
- **テキスト濃**: `#333333` (ダークグレー)
- **カード背景**: `#FFFFFF` (白)
- **警告色**: `#D32F2F` (赤)

### レイアウト

- **ページサイズ**: 960 x 540ポイント (16:9横)
- **余白**: 上下40pt、左右60pt
- **コンテンツ幅**: 840pt

## ⚙️ カスタマイズ

### 色設定の変更

`コード.gs` の `色設定` オブジェクトで色を変更できます。

```javascript
const 色設定 = {
  背景色: '#FFF9E6',
  アクセント色: '#FF9500',
  // ...
};
```

### フォントサイズの調整

`コード.gs` の `フォントサイズ` オブジェクトで調整できます。

```javascript
const フォントサイズ = {
  タイトル: 32,
  見出し1: 24,
  // ...
};
```

## 🐛 トラブルシューティング

### 「Authorization required」エラー

初回実行時に認証が必要です。

1. 「承認が必要です」ダイアログで「権限を確認」をクリック
2. Googleアカウントを選択
3. 「詳細」→「(プロジェクト名)（安全ではないページ）に移動」をクリック
4. 「許可」をクリック

### タイムアウトエラー

分割生成方式を採用していますが、それでもタイムアウトする場合：

1. スプレッドシートのデータ量を減らす
2. 再度実行する（前回の途中から再開される場合があります）

### レイアウトがずれる

テキストが長すぎる場合、レイアウトがずれることがあります：

1. スプレッドシートの入力内容を簡潔にする
2. 手動でスライドを調整する
